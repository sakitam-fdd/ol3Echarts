WHY OL-ECHARTS

专注桥接，保持两端原生能力

01

原生坐标桥接

自动注册 OpenLayers 坐标系，把经纬度稳定映射到 ECharts 像素空间。

02

完整视图同步

平移、缩放、旋转与容器尺寸变化都能触发精确重绘，并保留图表交互。

03

现代 TypeScript API

支持 OpenLayers 7–10、ECharts 5/6，以及 Vite、Webpack 和 Rollup。
